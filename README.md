# 2026 Chocó Earthquake — Ground-Motion Records and ShakeMaps

This repository collects ground-motion data and visualization products associated with the **2026 Chocó earthquake in Colombia**. It is intended to provide access to earthquake recordings and interactive ShakeMaps for selected Colombian cities.

## Contents

| Product | Description | Status |
|---|---|---|
| **AT2 ground-motion records** | Acceleration time histories in `.AT2` format. | Available - v1.0 |
| **Flatfiles** | Tabular ground-motion and station information for analysis and comparison. | Available - v1.0 |
| **Interactive ShakeMaps** | HTML-based visualizations of ground-motion intensity for selected cities. | To be added |

### Cities covered by the ShakeMap collection

- Cali
- Manizales
- Armenia and Dosquebradas

## Repository structure

The repository currently contains the `AT2 V1.0/` directory with ground-motion recordings and Flatfile. interactive HTML ShakeMaps will be organized into dedicated directories as they are uploaded.

## Using the data

1. **AT2 records:** Import the acceleration histories using compatible ground-motion processing or structural analysis software. Check record headers for sampling information and units.
2. **Flatfile:** A the tabular datasets to show station metadata and ground-motion intensity measures (Rotd50).
3. **ShakeMaps:** Download the HTML files and open them in a web browser to explore the interactive maps.

## Versions and updates

**Version 1.0 — AT2:** Initial release of ground-motion recordings, flatfile and ShakeMaps.
